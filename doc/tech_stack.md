# Tech Stack

## Core

- **Next.js** — React framework, routing, SEO, and deployment
- **TypeScript** — Type-safe development
- **React** — UI components

## Styling

- **Tailwind CSS** — Main styling system
- **shadcn/ui** — Reusable accessible components
- **Lucide React** — Icons

## Animation

- **Motion** — Page transitions, text reveals, hover effects, and basic animations
- **GSAP** — Advanced scroll-based and timeline animations

## Visual / Data

- **SVG** — Custom 2D graphics, data-flow lines, nodes, and visual effects
- **D3.js** — Interactive Data Science visualizations when required

## Content

- **MDX** — Research notes, articles, and deep dives

## Deployment

- **Git + GitHub** — Version control
- **Vercel** — Hosting and deployment

## Package Manager

- **pnpm**
